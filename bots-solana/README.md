# Bots de Solana

Un vídeo por función. Cada carpeta es un bot de Telegram que puedes montar **en tu propio ordenador**, gratis, con tus claves. Al final, el bot que los junta todos y una mini app para manejarlo.

▶️ La serie en orden: [lista «Bots de Solana»](https://www.youtube.com/playlist?list=PLbRgpdRexHjI)

**Antes de empezar:** si no has creado nunca un bot de Telegram, mira primero [Tu primer bot de Telegram que te avisa](../curso-de-claude/18-tu-primer-bot-de-telegram/) (esa carpeta se abre el 2 de diciembre de 2026, con su vídeo). Cada carpeta lleva su `.env.ejemplo`: lo copias a `.env` y pones ahí TUS claves. Aquí no hay ninguna clave de nadie.

**¿No sabes programar?** En cada carpeta está la frase exacta para pedirle a Claude que te lo instale paso a paso.

## Los datos

Todo lo que se dice en los vídeos sale de datos medidos. Están publicados para que los compruebes tú, con tu IA o a mano: [rama «datos» de este mismo repositorio](https://github.com/Profesor-Diogenes/Profesor-Diogenes/tree/datos). Allí hay un LEEME que explica cada fichero, cada columna y cómo se mide el resultado sin hacer trampa con el futuro.

## Para qué sirve todo esto (y para qué no)

Sirve para mirar un token o una billetera con tus propias herramientas, sin pagar a nadie. No sirve para ganar dinero seguro: con cientos de miles de contratos medidos, no hemos encontrado una ventaja que aguante. Cada capítulo te da el número.

Esto no es consejo financiero. Es lo que miden nuestros datos.
